FUSION ALUNO — SINCRONIZAÇÃO AUTOMÁTICA ERP -> APP

Substitua somente este arquivo no repositório fusion-erp:

modules/treinos/aluno-app.service.mjs

O que esta versão faz:
1. A academia clica em "Código app" no aluno do ERP.
2. O servidor localiza o aluno no banco principal do Fusion ERP por tenant + CPF.
3. Sincroniza nome, CPF, WhatsApp/telefone, nascimento, matrícula, status e legacy_id
   no banco dedicado do Fusion Aluno.
4. Gera o código de ativação no banco do aplicativo.
5. Não exige cadastro duplicado do aluno.
6. Não envia foto/base64 para o banco do app.
7. Mantém as chaves secretas somente no servidor.

Variáveis Render já necessárias:
FUSION_APP_SUPABASE_URL
FUSION_APP_SUPABASE_SECRET_KEY

Nenhuma variável nova precisa ser criada.

Depois de substituir:
git add modules/treinos/aluno-app.service.mjs
git commit -m "fix: sincroniza aluno antes de gerar codigo do app"
git push origin main

A Render fará Auto-Deploy.
