Fusion ERP - P1 Provisionamento Fusion Aluno V1

Arquivos:
- scripts/provisionar-academia-fusion-aluno.mjs
- scripts/test-provisionamento-academia-fusion-aluno.mjs

Objetivo:
Eliminar a etapa manual de criar/vincular uma academia do ERP ao Fusion Aluno.

Segurança:
- O comando é dry-run por padrão.
- Para alterar o Supabase, exige ao mesmo tempo:
  --apply
  --confirmar=PROVISIONAR-ACADEMIA
- A RPC no Supabase é executável apenas por service_role.
- Chaves sb_secret_* são enviadas apenas no header apikey.
- Chaves JWT service_role legadas usam apikey + Bearer.
- O script não imprime a chave.
- Repetir o mesmo provisionamento é idempotente.

1) Testar a ferramenta localmente:
  node scripts/test-provisionamento-academia-fusion-aluno.mjs

2) Fazer apenas dry-run de uma academia:
  node scripts/provisionar-academia-fusion-aluno.mjs --tenant=academia-exemplo --nome="Academia Exemplo" --timezone=America/Maceio

3) Aplicar somente depois de revisar:
  node scripts/provisionar-academia-fusion-aluno.mjs --tenant=academia-exemplo --nome="Academia Exemplo" --timezone=America/Maceio --apply --confirmar=PROVISIONAR-ACADEMIA

Variáveis esperadas no .env:
- FUSION_APP_SUPABASE_URL
- FUSION_APP_SUPABASE_SECRET_KEY
  ou FUSION_APP_SUPABASE_SERVICE_ROLE_KEY

Não envie ou cole essas chaves no chat.
