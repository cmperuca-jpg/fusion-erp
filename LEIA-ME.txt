FUSION ALUNO — CORREÇÃO PARA DEPLOY

Esta correção faz apenas duas mudanças em:
modules/security/api-security.middleware.mjs

1. Remove o redirecionamento interno:
   www.fusionsistema.com.br -> fusionsistema.com.br

   A Render já está configurada para:
   fusionsistema.com.br -> www.fusionsistema.com.br

   Assim elimina o ERR_TOO_MANY_REDIRECTS.

2. Libera no middleware global somente as rotas necessárias do Fusion Aluno:
   POST /api/treinos/aluno-app/ativar
   POST /api/treinos/aluno-app/status
   POST /api/treinos/aluno-app/login
   POST /api/treinos/aluno-app/primeiro-acesso
   GET  /api/treinos/aluno-app/me
   POST /api/treinos/aluno-app/logout

Nenhuma outra API é aberta.

OPÇÃO A — PowerShell (Windows)
Na raiz do repositório fusion-erp:
  powershell -ExecutionPolicy Bypass -File .\CORRIGIR-FUSION-ALUNO.ps1 -Repo .

Depois:
  git diff -- modules/security/api-security.middleware.mjs
  git add modules/security/api-security.middleware.mjs
