FUSION ERP — CAMPOS VISÍVEIS NO CONFIRMAR RECEBIMENTO
07/08/2026

SIM: uma única regra CSS cobre todos os campos deste modal:
- Valor devido
- Valor pago
- Data do pagamento
- Forma de pagamento
- Bandeira
- Modalidade
- Parcelas
- Taxa %
- Taxa fixa
- Desconto
- Acréscimo/Juros
- Observação

A correção força:
color
-webkit-text-fill-color
opacity
autofill do Chrome/Edge
readonly/disabled
date
select
number
textarea
placeholder

IMPORTANTE
==========
A correção serve para TODOS OS CAMPOS do modal "Confirmar recebimento".
Ela não muda automaticamente campos de outras páginas/módulos.

COMO APLICAR
============
1. Substitua:
   public/pages/financeiro/recebimento-contraste.css

2. Na raiz do projeto execute:
   PowerShell:
   .\APLICAR-CORRECAO-FINANCEIRO.ps1

   ou Linux:
   bash APLICAR-CORRECAO-FINANCEIRO.sh

O script move o CSS de contraste para o final do <head> e troca a versão,
evitando que o tema global ou o cache do navegador vençam a correção.

3. Commit/push.
4. Aguarde o Render ficar Live.
5. No navegador: Ctrl+F5.
