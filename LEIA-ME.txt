OBJETIVO
========
Unificar a matemática financeira entre:
- Financeiro
- Mensalidades
- Recebimentos
- Pagamentos
- Caixa
- Relatório Diário de Caixa
- BI Financeiro
- Dashboard

CORREÇÕES PRINCIPAIS
====================
1) BRUTO - TAXA = LÍQUIDO
Quando existe taxa explícita, o líquido é recalculado por:
  líquido = bruto - taxa
Isso corrige registros históricos em que a taxa foi descontada duas vezes.

Exemplo auditado:
  R$ 65,00 - R$ 1,94 = R$ 63,06
e não R$ 61,12.

2) CAIXA
O Caixa agora valida:
  saldo bruto = entradas brutas - saídas brutas
  saldo líquido = entradas líquidas - saídas líquidas

O backend também cruza movimento com Financeiro/Recebimento/Recibo para
recuperar a taxa correta quando movimentos antigos não carregam a taxa.

3) BI FINANCEIRO
O frontend deixa de usar o valor original de título parcial como saldo pendente.
Agora usa:
  valorPendente

Exemplo:
  título R$ 5.700,00
  pago R$ 4.500,00
  pendente R$ 1.200,00

O saldo previsto inclui separadamente:
  realizado + aberto + programado

4) DEDUPLICAÇÃO DE RECORRÊNCIA
No BI, um título Programado redundante não é somado quando já existe a cobrança
emitida para o mesmo aluno/matrícula/plano/competência.

5) MENSALIDADES
- Programada futura permanece Programada.
- No vencimento passa a Aberta.
- Depois do vencimento passa a Atrasada.
- Registros futuros criados manualmente passam a nascer como Programados.
- Duplicidade Programada x Emitida é ocultada pela origem persistida, mesmo
  depois que o vencimento já passou.
- Saldo em atraso é reconstruído quando registros antigos guardaram saldo zero
  indevidamente.
- Mensalidade paga não volta a entrar em "valor previsto".

6) FUSO HORÁRIO
Mensalidades e Caixa passam a usar America/Sao_Paulo para a data operacional.

IMPORTANTE
==========
Este ZIP altera CÓDIGO. Ele não apaga nem modifica registros históricos no Supabase.

Os dois títulos Programados redundantes e o registro histórico com líquido incorreto
continuam existindo fisicamente no banco até uma reconciliação de dados específica.
O código deste pacote impede que essas inconsistências contaminem os principais
cálculos consolidados.

Depois do deploy:
1. Aguarde o Render ficar Live.
2. Faça Ctrl+F5.
3. Compare Financeiro, Caixa, Relatório Diário e BI.
4. Só depois faça a reconciliação física dos registros históricos.
