VÍNCULO DO APARELHO

O código permanente da academia NÃO vira senha de login.

Primeira vez naquele aparelho:
  academia + código
  -> servidor valida
  -> emite vínculo criptográfico do aparelho
  -> vínculo fica salvo no navegador/PWA

Próximos logins naquele aparelho:
  e-mail + senha
  -> sem pedir o código da academia novamente

O vínculo:
- não autentica o usuário;
- apenas identifica a academia;
- tem validade configurável (padrão 180 dias);
- é revogado automaticamente se o código permanente da academia for regenerado.

Se o aparelho perder dados/localStorage ou o dono regenerar o código:
  o código da academia será solicitado novamente uma vez.

IDENTIDADE VISUAL

Nas rotas /NOME-DA-ACADEMIA/... o servidor injeta o contexto do tenant.
O script fusion-tenant-experience.js:
- troca o título do navegador para o nome da academia;
- troca a marca do menu superior para o nome da academia;
- usa o logo salvo quando existir;
- reescreve links técnicos /pages/... para URLs limpas da academia;
- mantém "Tecnologia Fusion Sistema" como identidade secundária.
